# Punctuation: compare marks, not sentence meaning

Perform this pass on every text-bearing region before marking its punctuation_spacing check complete. Use the union of marks visible in both images, including marks omitted by OCR. Do not restrict inspection to the example below.

1. Locate every punctuation occurrence independently in each native image. Anchor it to an item ID and word/character position. Include quotes at BOTH ends, apostrophes, commas, periods, colon/semicolon dots, parentheses, hyphens/dashes, slashes and decimal separators. Inspect abbreviation endings, auxiliary codes and the copyright line.
2. Open paired native crops with the adjacent word and baseline visible. Use nearest-neighbour enlargement as an aid, not as new detail. A quotation mark may be only a few source pixels: do not assign a Unicode identity when those pixels cannot resolve it.
3. For each occurrence compare: number of components; position above/on/below the text baseline; curl, tail and slant direction; length; distance to the adjoining word; and whether a mark is attached, lost or added. Compare a comma's tail versus a period, both dots of a colon, each stroke of a double quote, and opening versus closing forms separately.
4. Record original and enhanced observations in the punctuation evidence for the item. Example structure: `after Zahl: original two upper marks curling one direction; enhanced two upper marks curling the opposite direction; paired native crop paths and coordinates`. Preserve role-specific uncertainty. Quote count alone is insufficient.
5. Compare literal transcriptions without converting curly quotes to straight quotes, enforcing German grammar, normalizing dashes, deleting punctuation, or copying OCR from the other role. The comparison script exposes punctuation codepoints, names and offsets, but this only checks supplied strings. Equal strings require the same pixel inspection.
6. Sweep marks backwards through the region and reconcile against both images. A confirmed changed orientation/shape is a punctuation finding even if the word and number of marks are unchanged. Set punctuation_spacing to different; if direction/count is obscured, unresolved. Mark checked only after both sides have evidence for all occurrences. Annotate confirmed marks on the enhanced image, with the card ID; keep unresolved marks separate.

Historical example: Fluffeluff 40/75, baby-Pokémon rule, `Zahl`. In the supplied 2026-09-28 pair, the closing double quotation mark has a different curl/direction across the native crops, while both sides still have double marks. The opening mark alone does not prove the pair matches. This is evidence for this pair only; never prefill it on another card. Do not report a correction to `Kopf` when the actual supplied card says `Zahl`.

Software regression examples should include `„Zahl”` versus `„Zahl“`, curly versus straight quotes, double versus single quotes, comma versus period, colon versus semicolon, missing final punctuation, and unchanged controls. Passing literal-string tests does not demonstrate automatic image detection.
